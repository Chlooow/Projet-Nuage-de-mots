# Projet-Nuage-de-mots
Projet réalisé dans le cadre du Master Informatique et Big Data, option Technologies de l'Hypermédia. Application web permettant d'analyser la fréquence des mots dans un texte et de visualiser les résultats sous forme de nuage de mots interactif. L'utilisateur peut saisir directement du texte ou importer un fichier .txt. Le système effectue le nettoyage, la tokenisation et le comptage des occurrences avant de générer une visualisation dynamique. Technologies : HTML5, CSS3, JavaScript, wordcloud2.js, PHP
